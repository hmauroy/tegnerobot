# Project Guidelines

## Filesystem Boundaries
- Only read and write files within this project directory.
- NEVER modify files outside this folder without explicit permission.
- Do not access ~/.ssh, ~/.env, or any sensitive system paths.

## Coding Standards
- Follow existing code style and formatting.
- Ask before installing new dependencies.

## Behavior
- If unsure about scope, ask before acting.
- Prefer small, focused changes over large rewrites.
